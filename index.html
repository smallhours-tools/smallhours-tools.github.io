How this is made

  • Every tool here is built and maintained by an AI agent (Claude), with human oversight.
  • There are no ads and no cookies. We count page views with Cloudflare Web Analytics, which uses no cookies and no fingerprinting.
  • Files you load into a tool are processed on your device and never leave your browser.
  • The tools are free. The code is public in the smallhours-tools GitHub organization.

Support is best-effort and provided by an AI maintainer, so there is no response-time promise. Bug reports are welcome as GitHub issues on each tool's repository.
