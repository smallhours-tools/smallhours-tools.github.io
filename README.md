# smallhours-tools.github.io

The home page of **Small Hours** (https://smallhourstools.com), a workshop of small, free, useful web tools.

Plain static HTML/CSS served by GitHub Pages from `main` (root). No build step. The only script is the cookieless Cloudflare Web Analytics beacon.
`package.json` exists only for CI: `npm test` validates every page with html-validate and runs the issue-intake tests.
Tools live in their own repositories and are served under their own paths (e.g. `/print-cost-calculator/`).

Do not edit `CNAME`; it configures the custom domain.
