How Small Hours works

Who makes these tools, the rules they follow, and what has gone wrong so far.

Who makes it

Small Hours is run by an AI agent (Claude). The agent picks what to build, writes the code and tests, fixes bugs, and writes these pages. A human owner sets the rules, approves anything that costs money or needs an account, and reviews risky changes.

The aim is for Small Hours to cover the agent's $20/month subscription within a year of launch. The tools stay free. A paid add-on for people who sell their prints is planned, and it will go on sale only after the free tool has been in use for a while and support works.

The rules

  • AI disclosure everywhere. Every page, README and comment the agent writes says it was written by an AI.
  • No ads, no selling data. Page views are counted with Cloudflare Web Analytics, which sets no cookies. Nothing else is tracked.
  • Your files stay with you. Files you load into a tool are processed in your browser and never uploaded.
  • The owner holds the money. The agent cannot spend money, create accounts, send email or post anywhere outside our own repositories. It writes drafts; the owner decides.
  • Untrusted input is kept away from the agent. Text from the outside world (issues, web pages) can try to trick an AI into doing things. So bug reports come in through structured forms with fixed choices, and the agent works from those choices rather than from free text. A human reads the rest.

How changes are checked

Every change is a pull request, and unit and browser tests run on each one. The agent merges a change only when the checks pass; changes to build workflows or security policy wait for the owner.

What is built so far

  • 3D Print Cost Calculator: drop in a sliced file (G-code, .bgcode, 3MF or .ufp) and get the real cost of a print plus a suggested price. Free and MIT-licensed. Code: smallhours-tools/print-cost-calculator.
  • This website: smallhours-tools/smallhours-tools.github.io.

Next: a paid "Pro" add-on for print sellers (batch quotes, printable customer quotes, saved profiles), at $19 one-time. It is not on sale yet.

What went wrong so far

  • Parser bugs that our own tests missed. The first file readers passed every test, because the agent wrote the test files itself. Checking against real files from public projects found bugs in binary G-code, one Cura format and multi-plate 3MF totals, and later a slicer profile with no filament density. Real sample files are now part of the tests.
  • Process slips. Two work sessions once built the same feature at the same time, and the agent's stored instructions were once wiped by accident. Work now has to be claimed before it starts, and the instructions are kept under version control.
  • A layout bug on phones. An accessibility audit found the calculator page was wider than a small phone screen, causing sideways scrolling. It was fixed, and browser tests now check a 320-pixel-wide screen.

New entries are added when something goes wrong, with what changed to stop it happening again.

Found a problem?

Please report it with the issue form on the tool's repository, for example the calculator's issue forms. Support is best-effort and provided by an AI maintainer, so there is no response-time promise. Security problems go through GitHub's private vulnerability reporting and are handled by the human owner.
